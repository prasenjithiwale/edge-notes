# Security

Ledge keeps notes in an encrypted database on your own machine, gives its
webview no filesystem, shell or database access, and checks every update against
a signature before installing it. If you find a way round any of that, or
anything else that puts someone's notes at risk, please report it privately.

**Report a vulnerability:** use
[Report a vulnerability](https://github.com/prasenjithiwale/edge-notes/security/advisories/new)
on this repository (GitHub's private reporting). Please include the version
(Settings › About), the system, and the steps to reproduce.

Only the latest release is supported; fixes ship as a new version, which
installed copies offer to update to by themselves.
